# Release Notes

This package is the first public GitHub export lane for `Inside the Terminal`.

What it tries to prove:

- a music video can be released as a reproducible system
- the render method is part of the work
- the public repo can recreate the released video without the wider Hedegreen Research repo

What it does not try to prove yet:

- that the tool is already a full generic product
- that every past experiment belongs in the public package
- that the production room and the public repo should be the same thing
